# portfolio

Personal portfolio of Muhammad Anshar Al Faruq, full-stack web developer.

**Live:** https://edfaruq.vercel.app

## Stack

- Next.js (App Router) + TypeScript
- Three.js for the WebGL terrain
- GSAP for animations
- Deployed on Vercel

## Structure

```
app/          routes, layout, icons
components/   UI and effects (components/fx for WebGL)
content/      portfolio text and project data
lib/          shared helpers
public/       static assets, including the CV PDF
```

Most text changes only touch `content/`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
